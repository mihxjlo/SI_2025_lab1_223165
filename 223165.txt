   14-17. Имплементација на првиот issue(и останатите 2)

   18-19. Креирање на pull request за првиот issue
Креирав pull request за спојување на првата гранка кон master преку Github интерфејсот.


   20-24. Спојување на два pull requests
Ги одобрив и споив две pull requests преку Github интерфејсот. 
Едниот го споив локално со git checkout master -> git pull origin master -> git merge 1-remove-a-task-by-name -> git add . -> git commit -m "Merge branch 1-remove-a-task-by-name" -> git push origin master. 
Стратегија:
$ git merge 1-remove-a-task-by-name
Auto-merging SI2025Lab1Main.java
Merge made by the 'ort' strategy.
(не се случија никакви конфликти)
